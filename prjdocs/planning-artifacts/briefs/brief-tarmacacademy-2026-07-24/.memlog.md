- (decision) Portée initiale: un seul tenant (ce projet), dogfooding avant toute ambition multi-équipes/multi-projets BMAD
- (decision) Accès Git complet et direct pour tous les utilisateurs, pas de copie/DB des documents; le profil choisi à la connexion (PM/Analyste/autre, changeable par session) ne filtre que l'affichage, jamais les droits
- (decision) output_folder doit toujours être lu depuis _bmad/core/config.yaml, jamais codé en dur (le nom change selon versions BMAD, ex prjdocs vs _bmad-output)
- (decision) Toute modification depuis le portail passe par une Pull Request, jamais de commit direct
- (decision) Approbation des PR routée par CODEOWNERS selon le chemin modifié: le PM valide seul les PR touchant uniquement output_folder; le reste (code) requiert Tech Lead ou Dev
- (decision) Dashboard: lit l'état d'avancement directement depuis les artefacts du repo (sprint-status, PRD, epics), une seule source de vérité pour dashboard et suggestions
- (decision) Suggestions d'actions contextuelles = menu de capacités de l'agent BMAD actif, filtré dynamiquement par ce qui manque dans le pipeline du projet, pas une liste statique par profil
- (decision) Chat = visibilité des actions de l'agent (fichiers lus/écrits, skills appelés, diff) sans édition inline type ghost-text, écartée pour limiter la complexité du MVP
- (decision) Moteur du chat abstrait dès l'architecture pour supporter Claude Agent SDK et GitHub Copilot Coding Agent; MVP cible Claude Agent SDK en premier (streaming natif, pas de palier de licence), connecteur Copilot en second (Agent Tasks REST API en polling sur Pro/Pro+/Max, vrai streaming réservé à Enterprise Cloud)
- (assumption) output_folder ne contient jamais de code exécuté, seulement des artefacts humains -- condition nécessaire pour que la règle CODEOWNERS PM-valide-seul reste sûre
- (event) Question ouverte non tranchée: faut-il un troisième profil lecture-seule sans chat pour un stakeholder externe?
- (event) Aucune validation externe du besoin à ce jour -- intuition du fondateur, pas encore confirmée par d'autres équipes
